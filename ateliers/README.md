# ateliers/

Un sous-dossier par atelier, pour les livrables qui ne sont pas du code :
notes d'analyse, comparaisons, décisions d'architecture, journal de session.

```
ateliers/
  A-socle/            CLAUDE.md commenté, relevé des conventions trouvées
  B-tests/            couverture avant/après, commande d'équipe
  C-diagnostic/       analyse du défaut, chronologie, correctif
  D-legacy/           explication de la routine Caché, tests de caractérisation
  E-automatisation/   crochets Git, canevas d'intégration continue, carte n8n
  F-gouvernance/      classification des données, politique complétée
```

Ces dossiers sont volontairement vides. Ce qu'on y dépose est ce qu'on emporte.
